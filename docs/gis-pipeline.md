# GIS pipeline

Recharge analysis is intentionally blocked until real, licensed, dated spatial inputs are configured. `/api/recharge/readiness` returns the known required/missing parameters, and `/api/recharge/analyze` returns an explanatory 409 without creating a prediction.

Expected inputs include a DEM with resolution and acquisition date, derived slope/aspect/flow rasters, drainage, geology, soil, land cover, and rainfall. Record source, date, resolution, license, processing steps, coordinate reference system, and quality checks per input. Use GeoPandas, Rasterio, Shapely, and PyProj only after those inputs and study area are provided.

Recharge boundaries must be sourced or generated by a documented analysis, validated as Polygon/MultiPolygon geometry, and reviewed in the field. Demo score rows do not have boundaries and are never drawn as map zones.
