# ML pipeline

There is currently no trained or scientifically validated model. Demo zone scores are synthetic UI/test fixtures and have no confidence value. The app must show confidence as unavailable rather than inventing it.

Before training, define target labels from validated field observations, split data by appropriate spatial/time groups to avoid leakage, track source data and model versions, and report evaluation metrics with limitations. Any result must be titled **Recharge Suitability** or **Probable Recharge Zone**, explain contributing inputs, and remain a decision-support output pending field validation and expert review.
